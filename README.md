# GameDan Team Web

Official website for **GameDan Team**, an independent game development studio creating memorable retro and anime-inspired games.

## Tagline

**Enjoy your gaming lifestyle.**

## Tech Stack

- Next.js
- React
- TypeScript
- CSS Modules
- CSS Design Tokens

## Current Version

`v0.3.0`

## Development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production Build

```bash
npm run build
```
