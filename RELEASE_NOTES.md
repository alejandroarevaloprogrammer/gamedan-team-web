# GameDan Team Web v0.3.0

## Release Goal

Create the first production-oriented Hero foundation for the GameDan Team website.

## Highlights

- The Hero now revolves around the current featured game.
- Game data has been centralized in `src/data/games.ts`.
- The project now has a proper game model in `src/types/game.ts`.
- Branding has been centralized in `src/config/brand.ts`.
- The Hero has been rebuilt as a complete component package.

## Next Release

`v0.4.0` should focus on the Featured Game section and the first Games Preview section.
