# Design System

## Visual Direction

The GameDan Team website should feel like the official website of an indie game studio, not a generic company landing page.

## Colors

Defined in `src/styles/tokens.css`.

Core colors:

- Pink: `#FF62BB`
- Purple: `#B331F1`
- Soft Pink: `#FF97D0`
- Cream: `#FBF5A7`
- Cyan: `#31F1B3`
- Dark Background: `#12051F`

## Images

Game key art should be treated as marketing artwork, not simple screenshots. Recommended key art ratio: `4:3`.

Screenshots may use different aspect ratios depending on the game.
