# GameDan Team Web

## Project Principles

This website is not a portfolio project.

It is the official website of GameDan Team, an independent game development studio.

Every technical and design decision should reinforce the studio's identity and showcase its games.

---

# Core Principles

## 1. Games are always the protagonist.

The website exists to present our games.

The studio comes second.

Every section should support this goal.

---

## 2. Design before code.

We design first.

We implement second.

We never code a component without understanding its purpose.

---

## 3. Build for the next five years.

Avoid quick fixes.

Prioritize maintainability.

Write code that will still make sense years from now.

---

## 4. Keep components small.

Every component should have a single responsibility.

If a component becomes difficult to understand, split it.

---

## 5. Performance is a feature.

Fast loading times are part of the user experience.

Animations should never reduce performance.

---

## 6. Consistency over novelty.

The interface should feel coherent.

Avoid introducing new visual patterns without a good reason.

---

## 7. Quality over speed.

There are no deadlines.

Every release should improve the project.

---

## 8. Accessibility matters.

Keyboard navigation.

Readable typography.

Semantic HTML.

Good contrast.

Accessibility is part of quality.

---

## 9. Mobile is not an afterthought.

Responsive behaviour is designed first.

Not fixed later.

---

## 10. Every detail matters.

Spacing.

Typography.

Animation.

Shadows.

Transitions.

Everything contributes to the final experience.

---

# Final Goal

Build a website that reflects the quality and passion behind GameDan Team and becomes the best possible showcase for its games.
